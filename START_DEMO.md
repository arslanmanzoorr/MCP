## ❓ Quick FAQ

**Q: Why can't I deploy on Vercel?**  
A: Vercel is for static sites/serverless. FastAPI needs a running server. Use Render/Railway for backend.

**Q: What's the fastest way?**  
A: Use ngrok (10 min) - see `QUICK_DEMO_GUIDE.md` Option 2

**Q: What's the most professional?**  
A: Deploy backend on Render + frontend on Vercel (30 min) - see `DEPLOYMENT_ALTERNATIVES.md`

**Q: Can I test locally?**  
A: Yes! Use `quick_demo.bat` (Windows) or `quick_demo.sh` (Mac/Linux)
